# Separate ChatGPT plugin candidates

The three directories are portable source candidates for Resonant Quantum Mechanics, WaveEngine and Robotics Lab. Each includes its own identity, skill and exact branded prepaid MCP audience. Cursor and Claude source packages remain under `../plugins/`; their host-specific HTTP and OAuth configuration is preserved.

ChatGPT registration, current consent, policy, paid result, useful output and original-key replay are separate acceptance stages. These candidates neither register an app nor change deployed credentials. Existing Jobs repository ChatGPT packages point to the shared federation and are not evidence that these prepaid audiences have been accepted. No substitution between the paths is allowed.

For current plugin format and remote connection requirements, use [OpenAI plugin docs](https://developers.openai.com/plugins/build/plugins) and [ChatGPT connection docs](https://developers.openai.com/plugins/deploy/connect-chatgpt). Do not claim nine-host acceptance from source validation alone.
