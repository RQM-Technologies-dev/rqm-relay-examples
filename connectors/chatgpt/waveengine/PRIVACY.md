# WaveEngine privacy notice

Publisher: RQM Technologies LLC. Privacy contact: jvg@rqmtechnologies.com.

This package sends selected tool arguments to `https://jobs.rqmtechnologies.com/mcp/plugins/wave`. Discovery sends a short query and product/list filters. Computation sends the selected capability, technical input, idempotency key and maximum price. Retrieval sends a job ID or original idempotency key. Do not send secrets, unnecessary personal information, unrelated files or full conversation history.

OAuth sign-in uses RQM Account Core at `account.rqmtechnologies.com` and the existing Firebase identity service. The host holds OAuth credentials; the package has no credential store. Each brand/client has a distinct delegated principal. Account Core enforces the saved owner policy and prepaid-credit reservations. Jobs dispatches accepted work to the existing company Workflow and product implementation. Hosting providers process execution data to deliver the service.

Raw inputs are not written to application diagnostic logs. Necessary execution inputs, results, job state, consent, identity, idempotency records, credit reservations, ledger records and receipts are durably stored for execution, retrieval, recovery and reconciliation. This is not zero retention. This credit contract does not promise the former subscription route's 30-day result-access cutoff. No unverified deletion interval is asserted; contact the publisher for applicable record retention and deletion policies.

The package contains only skills, manifests and remote MCP configuration. It has no local executable, analytics SDK, filesystem reader or wallet. `run_account_job` can spend existing prepaid credits within the owner's saved policy and the submitted price ceiling. The connector cannot fund credits, top up automatically, sign a wallet transaction or cancel a job. ChatGPT/Claude/Cursor process and retain conversation/tool data under their own policies.

Use private email for privacy requests. Do not post private inputs, tokens or results in public GitHub issues.
