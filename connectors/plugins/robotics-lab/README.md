# Robotics Lab candidate 0.4.0

This package targets the separately scoped prepaid Robotics Lab connector at `https://jobs.rqmtechnologies.com/mcp/plugins/robotics`. Cursor uses the public client ID `rqm-cursor-robotics`; Claude uses its supported OAuth registration flow. Neither manifest contains credentials.

The candidate requires the corresponding Core audience and Jobs route changes to be deployed before installation acceptance. The current live route may return 404. Package creation is not evidence of OAuth consent, a valid spending policy, payment, recovery or useful output. Do not fall back to shared discovery, subscriptions or another product.

Free discovery lists robotics contracts. The six tools are `list_buyer_jobs`, `search_buyer_jobs`, `get_account_balance`, `run_account_job`, `get_account_job` and `list_account_jobs`. Account-funded execution requires fresh consent, an owner-saved policy and approval for exact inputs and maximum price. Preserve the original idempotency key for recovery. No account funding or paid acceptance is performed by installation.

Computational robotics reports do not control hardware or establish physical safety.
