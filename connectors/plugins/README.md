# RQM discovery plugins

Three self-contained Cursor and Claude packages: Resonant Quantum Mechanics, WaveEngine and Robotics Lab. Each connects to the anonymous, two-tool `/mcp/discovery` endpoint. Apache-2.0 applies only inside the three package folders, not the rest of this repository or any proprietary service.

See each package's README, PRIVACY.md and listing.json. See SUBMISSION.md for publisher steps and acceptance evidence. These files do not establish installation, submission, approval or publication.
